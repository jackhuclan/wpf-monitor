# 需求文档：工业设备数据实时监控看板（WPF 桌面应用）

> 来源：微信公众号《WPF 工业设备数据实时监控看板（附源码）》（小码编匠，DotNet技术匠）
> 本文档从文章内容提炼，标注 **[假设]** 的条目为文章未明确说明、由实现方合理补全的信息。

---

## 1. 应用目标

面向**中小型工业现场**的设备实时监控平台，以 WPF 桌面客户端形式交付（不依赖浏览器）。核心定位：

- **打开就能看**：启动即进入监控界面，实时曲线无明显延迟感；
- **报警及时推**：阈值越限报警自动触发并记录，3 秒防抖避免边界抖动刷屏；
- **权限分清楚**：管理员 / 操作员 / 观察者三级权限，按钮级控制；
- **配置随时改**：阈值、刷新间隔等参数修改后**零停机热生效**，无需重启；
- **数据不丢失**：设备列表 JSON 持久化，用户与报警记录存 SQLite，关机重启后依然保留。

技术基线（沿用文章）：.NET 8 + WPF + MVVM（CommunityToolkit.Mvvm）、LiveCharts2（SkiaSharp 渲染）、HandyControl UI 库、Microsoft.Data.Sqlite、内置 DI 容器。

## 3. 界面结构

### 3.1 登录窗口
- 深色背景 + 品牌色点缀，居中卡片式表单，输入框带占位提示；
- 包含品牌标题「工业设备实时监控平台」、用户名、密码、登录按钮、错误提示；**[假设]** 卡片下方展示默认账号提示，便于开箱体验。

### 3.2 主窗口壳（三段式）
- **左侧边栏**：220px 宽、深色底；顶部品牌区，中部菜单项（图标 + 文字，按角色动态过滤），底部退出登录按钮与当前用户信息；
- **顶部 Header**：48px 高；左侧当前页面标题（面包屑），右侧实时时钟（秒级刷新）+ 当前用户名/角色；**[假设]** 用户头像用字形图标代替图片；
- **内容区**：浅灰底 (#F4F6FA)，白色圆角卡片，各功能页以 ContentControl 动态切换。

### 3.3 各功能页
- **首页仪表盘**：4 张统计卡片（设备总数/在线设备/今日报警/平均温度），在线率进度条，系统信息卡（版本、启动时间、运行时长、刷新间隔）；**[假设]** 卡片配彩色图标底块。
- **实时监控**：顶部 TabControl 切换设备；当前值区（温度/压力实时值 + 报警灯）；中部双通道折线图（左轴温度、右轴压力，阈值虚线）；下方最近报警列表；**[假设]** 顶部右侧显示滑动窗口点位数。
- **报警中心**：顶部筛选条（类型下拉 + 刷新按钮）；DataGrid 列表，类型列以红/蓝彩色标签呈现，内容列直接显示「温度 87.5℃ > 85℃」；底部分页条。
- **设备管理**：顶部工具条（新增设备按钮）；列表含状态圆点（绿=正常/红=报警）、设备编号、名称、在线状态、操作列（编辑/删除）；新增/编辑为行内表单面板。
- **历史记录**：日期范围（开始/结束 DatePicker）+ 设备下拉 + 查询按钮；DataGrid + 分页。
- **系统设置**：参数表单（温度阈值、压力阈值、刷新间隔 ms、滑动窗口、报警防抖秒）+ 保存按钮；分隔线下方修改密码区（旧密码/新密码/确认）。
- **用户管理**：新增用户表单（用户名/密码/角色下拉）+ 用户 DataGrid + 启用/禁用按钮。

## 4. 交互流程

1. **启动 → 登录**：首次启动自动创建 `users.db` 与 `devices.json` 并写入默认账号/设备 → 显示登录窗 → 校验通过进入主窗口，失败显示红色错误提示。
2. **导航**：点击侧边栏菜单 → 内容区切换页面、Header 标题同步；菜单按角色过滤；观察者登录后操作类按钮整体隐藏。
3. **实时监控**：数据模拟器（生产者-消费者模式）高频产点 → 图表按刷新间隔（默认 400ms）批量刷新滑动窗口 → 每个数据点进入报警引擎：连续越限超过防抖秒数（默认 3s）则落库报警并在设备页与报警中心可见；报警灯在越限期间呼吸闪烁，恢复正常后熄灭。
4. **报警处置**：报警中心按类型筛选 → 分页浏览 → 无需进入详情即可读到阈值上下文。
5. **设备维护**：新增设备立即持久化并出现在监控 Tab 中；删除前弹确认框。
6. **参数调整**：系统设置保存 → 写 appsettings.json → 文件监听触发热重载，阈值/刷新间隔/窗口大小立即作用于图表与报警引擎，无需重启。
7. **退出登录**：侧边栏底部退出 → 停止数据模拟 → 返回登录窗。

| 字段 | 类型 | 说明 |

| Name | string | 设备名称 |
| IsOnline | bool | 在线状态 |
| **[假设]** Unit | string | 备注（默认空） |

### 5.5 MonitorConfig（appsettings.json，支持热重载）
| 字段 | 默认值 | 说明 |
|---|---|---|
| TemperatureThreshold | 85.0 | 温度报警阈值 ℃ |

## 6. 关键约束

1. **报警防抖**：阈值边界来回跳动不得刷屏——连续越限达 `AlarmDebounceSeconds` 才触发一次记录；未越限即重置计时。
2. **配置热重载**：修改 appsettings.json 后程序自动感知并生效，全程不重启；程序内保存同样立即生效。
3. **权限到按钮级**：观察者登录后操作类按钮**直接隐藏**（非禁用），避免误触；用户管理页仅管理员可见。
4. **持久化**：设备列表 JSON 文件、用户/报警 SQLite 数据库；重启程序或重新登录后数据均在。
5. **实时性**：图表按刷新间隔批量更新滑动窗口，生产者-消费者解耦数据产生与界面渲染。
6. **MVVM 分层**：Model / ViewModel / View / Service / Converter 标准分层，依赖注入管理生命周期，界面与业务低耦合。
7. **观察者视角**：仅可查看（仪表盘/实时监控/报警中心/历史记录），无法进入设备管理、系统设置、用户管理。
8. **[假设] 密码强度**：修改密码要求长度 ≥ 6 且两次输入一致；默认账号仅用于首次开箱。
9. **[假设] 分页大小**：报警中心与历史记录每页 20 条，页码条提供上一页/下一页与页码信息。
10. **[假设] 温度曲线在左轴、压力曲线在右轴**（数量级差异大，双轴展示），阈值虚线绘制在各自轴上。
